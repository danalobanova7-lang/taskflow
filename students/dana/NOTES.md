# Заметки по Git и Git Flow

## Git — 5 фактов
1. Git — программа контроля версий, работает локально.
2. Три зоны: рабочая директория, staging, репозиторий.
3. `git add` — положить изменения в staging.
4. `git commit` — сохранить снимок в истории.
5. `git status` показывает, где что находится.

## Git Flow — 5 фактов
1. `main` — боевая ветка, только релизы.
2. `develop` — интеграция следующего релиза.
3. `feature/*` создаётся от `develop` и вливается в `develop`.
4. `release/*` — подготовка релиза, вливается в `main` и `develop`.
5. `hotfix/*` — срочный фикс от `main`, вливается в `main` и `develop`.

## Таблица веток Git Flow

| Ветка | Откуда создаётся | Куда вливается | Зачем |
|-------|------------------|----------------|-------|
| main | — | — | боевая линия |
| develop | main (один раз) | main (через release) | сборка следующего релиза |
| feature/* | develop | develop | одна задача |
| release/* | develop | main и develop | подготовка релиза |
| hotfix/* | main | main и develop | срочный фикс прода |
